# ⭐ Star Wars V: O Império Contra-Ataca
   🔗 **Veja online:** https://lucasnegri7.github.io/ProjetoStarWars/

Página web inspirada na abertura clássica de **Star Wars – Episódio V: O Império Contra-Ataca**, desenvolvida com **HTML**, **CSS** e **JavaScript** para praticar a criação de páginas com estilo e interação.

> *"Há muito tempo, em uma galáxia muito, muito distante..."*

## 🎬 Sobre o projeto

A página reproduz a abertura do filme: a frase de introdução, o logotipo da saga em SVG, o título do episódio e o texto de abertura em português, acompanhados pela trilha sonora do filme.

## ✨ O que o projeto tem

- Frase de introdução "Há muito tempo, em uma galáxia muito, muito distante..."
- Logotipo **STAR WARS** em **SVG**, na cor amarela característica
- Título "Episódio V – O Império Contra-Ataca" e texto de abertura em português
- Trilha sonora (`media/star_wars_theme.mp3`) configurada para tocar em loop
- Layout com **Bootstrap** e estilos próprios em `css/style.css`

## 🛠️ Tecnologias

| Tecnologia | Uso |
|------------|-----|
| HTML5 | Estrutura da página e elemento de áudio |
| CSS3 | Estilização e layout (`css/style.css`) |
| JavaScript | Comportamento da página (`js/script.js`) |
| Bootstrap | Base de estilos e componentes |
| jQuery 3.7.1 | Manipulação da página |
| SVG | Logotipo da saga |

## 🚀 Como executar

Não é necessário instalar nada.

1. Clone o repositório:
   ```bash
   git clone https://github.com/LucasNegri7/ProjetoStarWars.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd ProjetoStarWars
   ```
3. Abra o arquivo `index.html` no navegador (dois cliques no arquivo ou arrastando-o para uma janela do navegador).

> 🔊 **Dica:** se o áudio não tocar sozinho, clique na página. Muitos navegadores bloqueiam a reprodução automática de som até que a pessoa interaja com a página.
